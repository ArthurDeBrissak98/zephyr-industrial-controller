# Прототип управления насосом и приточкой на Zephyr

Прототип для управления частотником (VFD) на Zephyr под симулятор `native_sim`.

## Зачем это всё
Хотелось сделать универсальное ядро. Есть переключение профилей в терминале. Теперь та же самая прошивка управляет и насосом, и приточной установкой.

## Что внутри (как оно работает)
* **Потоки:** Сделал 3 штуки (sensor, control, monitor) + CLI и Modbus. Общаются между собой через очереди сообщений (`k_msgq`). 
* **ПИД:** Целочисленный (fixed-point). Сначала хотел на `float`, но потом узнал, что на реальном железе это тратит такты на FPU, и переделал на инты. Есть anti-windup.
* **Защиты (Interlocks):** Сделал через битовые маски аварий. Если сухой ход, обрыв 4-20мА или перегруз — контроллер сразу рубит частоту в 0 (E-Stop). 
* **Профили:** 
  * `PROFILE_PUMP` (Насос): уровень воды, защита от сухого хода.
  * `PROFILE_AHU` (Приточка): температуры (приток, улица, теплоноситель) и контроль фильтра.
* **Физика:** Старался сделать правдоподобно. Ток двигателя считается как квадрат частоты. Температура приточки реагирует на частоту.
* **Тесты:** Логика ПИД-регулятора покрыта юнит-тестами (Ztest), запуск автоматизирован через `twister` и CI/CD.
